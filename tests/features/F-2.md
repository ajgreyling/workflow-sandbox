# F-2: Blue/red toggle button

## F-2-T1: Button is blue by default

**Steps**
1. Open the base URL.

**Expected**
- The toggle button is visible and has a visible label or accessible name.
- The button's background colour is blue.
- No errors appear in the browser console.

## F-2-T2: Pressing the button turns it red

**Steps**
1. Open the base URL.
2. Click the toggle button once.

**Expected**
- The button's background colour is red.

## F-2-T3: Pressing the button again turns it back to blue

**Steps**
1. Open the base URL.
2. Click the toggle button once.
3. Click the toggle button again.

**Expected**
- After step 2 the button is red.
- After step 3 the button is blue.

## F-2-T4: Repeated presses keep alternating

**Steps**
1. Open the base URL.
2. Click the toggle button five times, checking the colour after each click.

**Expected**
- The colour alternates red, blue, red, blue, red.
- No errors appear in the browser console.

## F-2-T5: Colour is not persisted after reload

**Steps**
1. Open the base URL.
2. Click the toggle button once so it is red.
3. Reload the page.

**Expected**
- After reload the button is blue.

## F-2-T6: Colour is not shared with a new tab

**Steps**
1. Open the base URL.
2. Click the toggle button once so it is red.
3. Open the base URL in a new tab.

**Expected**
- In the new tab the button is blue.
- In the original tab the button is still red.

## F-2-T7: Button can be pressed with the keyboard

**Steps**
1. Open the base URL.
2. Press Tab until the toggle button has focus.
3. Press Enter.
4. Press Space.

**Expected**
- After step 3 the button is red.
- After step 4 the button is blue.
