# F-1: Simple demo web app

## F-1-T1: Page loads without errors

**Steps**
1. Open the base URL.

**Expected**
- The page loads and shows a visible heading.
- No errors appear in the browser console.

## F-1-T2: Controls are present

**Steps**
1. Open the base URL.

**Expected**
- At least three interactive controls (e.g. buttons, inputs, checkboxes, selects) are visible.
- Each control has a visible label or accessible name.

## F-1-T3: Each control does something

**Steps**
1. Open the base URL.
2. Use each interactive control once (click buttons, type into inputs, toggle checkboxes, change selects).

**Expected**
- Each interaction produces a visible change on the page.
- No errors appear in the browser console.
